# VNote – Android layihəsi

www/            tətbiqin özü (Netlify-a yükləsən PWA kimi də işləyir)
BUILD-APK.yml   GitHub-da APK-nı avtomatik yığan skript

Hədəf: Android 15 (targetSdk 35), minimum Android 6.
